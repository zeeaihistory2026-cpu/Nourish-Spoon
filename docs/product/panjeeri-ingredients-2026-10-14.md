# Panjeeri ingredient source

Published ingredients: almonds, walnuts, cashews, raisins, dry dates, cardamom, coconut, semolina (suji), pure desi ghee, lotus seeds, pumpkin seeds, sunflower seeds.

Both received Classic Panjeeri variants use this website ingredient list for their display cards. The owner-supplied catalogue additionally lists khoya; added sugar is shown only for the with-sugar variant. Labels and recipe differences still need confirmation before allergy-sensitive purchases. The generic website nutrition table is not assigned to the two sugar-specific variants without verified variant values.

All twelve Panjeeri ingredient PNGs are original website files downloaded unchanged from the live product page image URLs. Their source URLs and SHA-256 hashes are recorded in apps/mobile/assets/website/ingredients/sources.json. Each image uses contain sizing and an ingredient accessibility label.
